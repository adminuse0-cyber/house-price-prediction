# 🏡 House Price Prediction System

An end-to-end Machine Learning web application built using Python, Scikit-Learn, and Streamlit. This app predicts residential property prices based on key features like square footage, number of bedrooms, and bathrooms.

---

## 🚀 Live Demo
🔗 **[Click Here to Access Live Web App]([https://tamari-streamlit-link.streamlit.app](https://house-price-prediction-vsirofuawyktwh7fselfma.streamlit.app/))**

---

## 📌 Project Features
- **Data Preprocessing & EDA**: Cleaned and generated tabular datasets for accurate model execution.
- **Machine Learning Model**: Built using Linear Regression to estimate housing values.
- **Interactive UI**: Real-time user input interface designed with Streamlit.
- **Cloud Deployment**: Deployed live on Streamlit Community Cloud.

---

## 🛠️ Tech Stack & Libraries
- **Language**: Python
- **Machine Learning**: Scikit-Learn
- **Data Processing**: Pandas, NumPy
- **Web Framework**: Streamlit
- **Deployment**: Streamlit Cloud, GitHub
